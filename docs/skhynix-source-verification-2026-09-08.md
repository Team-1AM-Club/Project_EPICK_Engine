## 첨부에서 추가로 확인한 내용

공고에 연결된 PDF 3개는 모두 HTTP 200으로 내려받았고 PDF 파일 형식도 확인했다. 웹 읽기 도구의 `application/octet-stream` 처리 실패는 파일 부재가 아니었다. 텍스트 추출 결과가 비어 있어 페이지를 렌더링해 읽었다.

| 첨부 | 분량 | 이번에 자세히 확인한 범위 |
|---|---:|---|
| 국문 JD | 28쪽 | 표지, 10쪽 IT, 28쪽 공통 안내 |
| 영문 JD | 27쪽 | 10쪽 IT의 대응 내용 |
| FAQ | 6쪽 | 전체 페이지, 특히 2~5쪽 본문과 예외 |

파일명에는 이천이 있지만 국문 표지는 이천·분당·서울을 함께 표시한다. **IT 10쪽 자체의 근무지 표시는 이천**이다. 다른 직무 페이지의 지역을 IT에 합치지 않았다.

IT 업무에는 소프트웨어, 자동 반송 설비, 플랫폼, 데이터 처리, 기준정보 관리, 전산 인프라가 포함된다. 경험과 관련된 우대 항목은 다음 다섯 묶음으로 확인했다.

| 구분 | 확인한 범위 |
|---|---|
| 소프트웨어 | 프로그램 설계·개발 경험 |
| 데이터·개발 환경 | DBMS 또는 오픈소스 활용 |
| AI 응용 | AI 애플리케이션 구현·적용 경험 |
| 자동화 | 반송 설비의 하드웨어·소프트웨어 이해 |
| 기술 활용 | 새로운 IT 기술의 학습·프로젝트 적용 |

이 다섯 항목은 **우대 경험**이다. 열거된 기술을 모두 보유해야 한다는 필수조건으로 바꾸지 않는다. 국문에는 Python·JavaScript 예시가 있으나 영문 대응 목록에는 없다. 두 언어본을 동일한 기술 목록으로 자동 병합하지 않았다. 근거: [국문 JD 10쪽](../output/source-verification/2026-09-08/jd-ko-icheon.pdf#page=10), [영문 JD 10쪽](../output/source-verification/2026-09-08/jd-en-icheon.pdf#page=10).

## 필수·우대·예외를 분리해야 하는 사례

- 학위 배경과 관련 전공은 JD에 있지만, FAQ는 충분한 역량을 갖춘 다른 전공자의 지원도 허용한다. 전공명이 다르다는 이유만으로 경험을 제거하지 않는다.
- FAQ는 다른 업계의 인턴 경험도 직무역량·가치관을 보여 주면 활용할 수 있다고 설명한다.
- IT 코딩테스트에는 C 또는 C++ 선택 안내가 있다. 이는 시험 안내이며 모든 프로젝트를 해당 언어로 수행해야 한다는 뜻은 아니다.
- 어학 점수를 일괄 필수로 두지 않으며, 외국어 능력이 포함된 직무의 별도 평가 범위를 보존한다.
- 전역 기한은 일반 안내와 박사 예외가 다르다. 전문연구요원에는 별도 조건이 있다. 자동 자격 판정식은 만들지 않았다.

근거: [국문 JD 10쪽](../output/source-verification/2026-09-08/jd-ko-icheon.pdf#page=10), [FAQ 3~4쪽](../output/source-verification/2026-09-08/faq-ko.pdf#page=3). 이 내용은 해당 상반기 공고 범위의 안내다.

## 검증 기록의 의미와 남은 경계

- 원본의 검증 대기 상태를 조용히 덮어쓰지 않고 별도 결과에서 `SUPPORTED_WITH_SCOPE`로 기록했다. 이는 위 범위에서 공식 출처와 대조한 결과다.
- 새로 확보한 파일에 해시를 붙였다. 9월 7일 당시 수집한 보존본이 없으므로 당시 파일과 동일했다고 주장하지 않는다. 로컬 식별자는 누락된 W2의 전역 버전 ID를 대신하지 않는다.
- 공고 게시일과 마감 시간대는 미확인으로 유지했다. 기사에는 게시·수정 시각 메타데이터가 있지만 정책 적용일로 복사하지 않았다.
- IT 외 모든 직무의 상세 요건, 국·영문 전체 번역 일치성, 현행 다른 공고까지 검증한 결과는 아니다.
- 웹사이트 이용조건이나 운영 서비스의 사용권을 별도로 판정한 문서는 아니다. 이번 작업은 제공 자료의 출처 대조와 로컬 검토다.
- 경험 필터, 추천 가중치, 실제 자소서 문항, 운영 W4 입력은 생성하지 않았다. 다음 기준 정리에는 대상 채용 시점과 실제 문항을 명시해야 한다.

검증 기록의 출처·근거 참조와 해시 일치, HTML 짧은 발췌의 위치를 점검했다. PDF 근거는 지정 페이지를 직접 읽은 기록이며 OCR 자동 검증 결과가 아니다.
