아래는 v2 당시 기록이다. 이후 정답·오류 검토와 새 사례의 A/B 비교는 [v3 보고서](w4-review-v3-2026-09-09.md)에 있다.

실행일: 2026-09-08, 최종 기록 검증: 2026-09-09. 경험별 호출, 평가 항목 분리, 원문부터 추천까지의 실제 시연, 네 모델 재비교를 완료했다.
문항·매칭 종합 점수는 **Qwen3-14B**, 추출 구간 전체 일치율은 **Gemma 4 12B**가 가장 높았다.
그러나 필수 검증을 모두 통과한 모델은 없고 정답·정책도 미검토 초안이므로 **최종 모델 선정은 `WITHHELD`**다.

모든 성적은 아래 가상 자료와 설치된 양자화 파일에 한정된다. 일반적인 모델 성능 순위나 실제 지원자의 추천 정확도가 아니다.

## 구현과 실행 범위

1. 문항 분석 1회 후 경험마다 한 번씩 호출한다. 각 응답의 경험·버전·근거 ID를 즉시 검사하고 코드가 결과를 모아 정렬한다.
2. JSON 파싱, 출력 구조, 참조 계약, 문항 기준, 문항 인용, 경험 매칭, 위험한 근거 채택을 나누어 채점한다. 추출 점수는 별도로 유지한다.
3. 실제 모델로 가상 원문 4개를 다시 추출하고 협업·학습 문항에 각각 추천했다. 네 모델의 **추천 실행 8건 모두 끝까지 완료**했다.
4. 같은 프롬프트·자료·생성 조건으로 **평가 208회 + 시연 56회 = 실제 호출 264회**를 기록했다. 상용 API는 호출하지 않았다.

평가용 경험 판단 112회와 시연용 32회에서 모두 입력 경험 1개에 동일 ID의 응답 1개를 받았다. 이번 실행의 후보 누락은 0건이다.
이는 이번 요청 경계에서 확인한 결과이며 모든 입력에서 누락이 없어졌다는 보장은 아니다.

협업 문항의 표시는 ① 도서관 예약 도구 개선, ② 팀 프로젝트의 API 협업과 오류 개선, ③ 팀의 성과만 기록한 협업 경험이다.

따라서 1번이 2번보다 실제 역량이 뛰어나다는 의미를 부여하면 안 된다.

성공 사례와 함께 오류도 남겼다. Qwen3.5 협업 시연은 책임감 기준을 추가했고, Qwen3-14B·Qwen3.5·Gemma 12B 학습 시연은

**실행 완료 상태는 추천 내용의 정답 판정이 아니다.** 모든 모델의 출력은 같은 결과 폴더에서 확인할 수 있다.

## 검증과 남은 작업

- Python 3.12.14에서 API를 포함한 **187개 테스트 통과**. 경험별 호출, 다른 경험 ID 거부, 인용 확장·의미 구간 누락 구분, 확인 필요 상태와 선정 차단 등을 확인했다.
- 저장된 실제 응답으로 두 보고서를 다시 계산해 동일함을 확인했다. 264개 HTTP 기록과 평가 입력·응답, 모델 파일 해시 메타데이터를 대조했다.
- 실제 추출·추천의 원문 발췌 210항목에서 위치·문자열·경험/버전 참조 일치를 확인했다. 같은 근거의 재참조를 포함하며 분류 정확도 검증을 대신하지 않는다.
- 실행 전 기록한 코드 24개와 런타임의 해시가 현재 파일과 같았다. Python 파일 37개의 3.10 문법 호환과 공백을 검사했다. 3.10 런타임 테스트는 아니다.
- 실행기가 시작한 `llama-server` 프로세스와 18080 포트 리스너가 남아 있지 않음을 확인했다.

다음은 **사람이 정답·오류 사례를 검토하고, 계획·팀 행동·역할/행동 혼동을 개선한 뒤 또 다른 새 사례로 재평가**하는 작업이다.
문항·매칭 최고점과 추출 최고점이 다르므로 단계별 후보를 유지하되 현재 점수만으로 어느 모델도 자동 채택하지 않는다.
상용 API가 준비되면 같은 `JsonClient` 계약으로 비교에 추가할 수 있다.

별도로 SK하이닉스 문항 5개·내용 점검 10개 초안의 자동 적용, Graph·Vector 후보 검색, 팀 백엔드 인증 연결은 남아 있다.
시연의 경험과 기업 평가 맥락은 개발용 가상 자료이며 실제 지원서 요구조건의 확정이나 기업정보 검증 결과로 사용하지 않는다.
