# W4 평가 정답·가중치 검토안

상태: **DRAFT — 사람이 아직 승인하지 않은 AI 작성 가상 초안**.

이 문서와 연결된 JSON의 정답을 검토한 뒤 수정 또는 승인한다. 이 초안으로 실제 모델 점수를 매기거나 추천하지 않는다.

제안: 문항 해석 50%, 경험 매칭 50%, 각 사례 3회 반복. 한 사례의 판단 전체가 승인된 정답 중 하나와 일치하면 1점이다. 각 축에서 모든 사례의 비중은 같다.

문항 8개·매칭 7개로 모델당 예정 요청은 45회다. 비용·지연은 현재 요청한 두 기준의 종합 점수에 넣지 않는다.

문항 기준의 인용 범위, 확인 필요 여부, 근거의 사용 여부와 문제 코드, 연결할 ACTION 근거까지 검토 대상이다. 타당한 대체 정답은 JSON의 answers 목록에 추가할 수 있다.

## 1. paraphrase

상반된 입장을 가진 구성원들이 같은 결론에 도달하도록 기여한 사례에서 본인의 역할과 행동 및 결과를 설명해 주세요. 700자 이내

검토 메모: 협업이라는 단어 없이 의견 조율 행동을 협업에 연결. 개인 오류 수정은 협업과 무관. 기존 가상 샘플이지만 이 정답은 아직 사람 미승인.

제안한 문항 해석:

- 기준: `collaboration` (협업·조율) / 문항 인용: “상반된 입장을 가진 구성원들이 같은 결론에 도달하도록 기여한 사례”
- 필요한 근거: ROLE, ACTION, RESULT
- 확인 필요: 아니오

### 경험: 서로 다른 요구를 하나의 안으로 정리 (`episode-common-plan`)

## 승인 범위

위 8개 사례의 정답·허용 인용 및 연결, 정확 일치 채점 방식, 두 축 50:50, 동일 사례 비중, 3회 반복을 함께 검토한다. 잘못되었거나 해석이 여러 개인 사례는 수정하거나 대체 정답을 추가한다.

이 초안은 계산·연결 확인에 쓰는 작은 개발 세트다. 승인돼도 여러 실제 모델의 응답을 수집하기 전에는 추천 결과가 없다. 실제 모델 선정 전에 독립된 평가 사례를 추가하는 것이 필요하다.
