# W4 LLM 연결 코드 리뷰

검토일: 2026-09-08. 범위: 의미 판단 어댑터, Solar 전송, 가상 데이터 제한,
FastAPI 연결부, CLI와 실행 스크립트. 로컬 코드 검토이며 팀 PR 승인을 의미하지 않는다.

## 발견해 수정한 사항

| 문제 | 수정과 검증 |
|---|---|
| `SYNTHETIC` 표시만 믿으면 잘못 표시한 실제 데이터가 전송될 수 있음 | 문항과 경험 내용 해시를 가상 샘플과 대조. 가상으로 표시한 다른 문항·수정한 경험에서 HTTP 요청 0회 확인 |
| 허용되지 않은 경험을 두 번째 요청에서 검사하면 문항 호출 비용이 먼저 발생함 | 첫 호출 전에 전체 후보 내용 확인. 미등록 경험에서 모델 호출 0회 확인 |
| 응답 수신 중 연결 종료가 일반 예외로 빠질 수 있음 | `HTTPException`을 안전한 전송 오류로 변환. `IncompleteRead`의 원문 일부가 오류에 노출되지 않는지 확인 |
| 기존 출력 파일을 모델 호출 뒤 확인하면 결과 저장 없이 비용만 발생함 | 호출·클라이언트 생성 전에 경로 확인. 저장 시 배타적 파일 생성도 유지 |
| 스크립트가 다른 Python을 골라 설치된 API 테스트를 생략할 수 있음 | 프로젝트 `.venv` 우선 선택. 실제 PowerShell 실행으로 API 포함 82개 통과 확인 |
| 모델 응답용 파서의 코드 블록 허용이 HTTP 입력에도 적용되고, 잘못된 Unicode가 나중에 인코딩 오류를 일으킬 수 있음 | HTTP는 순수 JSON 객체만 허용. 잘못된 Unicode·중복 키·NaN을 입력 및 모델 응답 경계에서 거부 |

CLI 출력 캡처 환경에서 stderr 인코딩 설정 오류도 수정했다.
HTTP 테스트는 HTTPX ASGI 전송으로 실행하며 실제 서버나 외부 모델 호출을 사용하지 않는다.

## 확인한 핵심 경계

타 사용자·제외·이전 버전 경험은 모델 입력에서 제외된다. 원문과 다른 기술·수치,
다른 경험의 fact 참조, 누락·중복된 모델 응답, 임의 rank/status/score를 거부한다.
허용된 ACTION 참조만 추천 기준에 연결하며 순위는 코드로 계산한다.

API 인증 함수와 모델 팩터리는 서버가 제공한다. 요청 JSON으로 인증 사용자나 공급자 설정을 바꿀 수 없다.
실제 HTTP 수신량을 제한하고 동기 모델 작업은 이벤트 루프 밖에서 실행한다.
고정 HTTPS 목적지, 리다이렉트 차단, 응답 크기 제한, 안전한 오류 코드와 자동 재시도 금지를 확인했다.

## 검증과 잔여 한계

- Python 3.12.14, 프로젝트 격리 환경에서 테스트 **82개 통과**. Solar HTTP는 모의 응답이다.
- `git diff --check`, 잠금 파일 일치 확인(`uv lock --check --offline`), Python 파일 19개의 3.10 문법 검사,
  가상 샘플 원문 위치 검사와 새 파일을 포함한 공백 검사도 통과했다. Python 3.10 런타임 실행 검증은 아니다.
- 실제 Upstage 키 미발급으로 인증·모델 응답 형식·의미 정확도·비용·지연 시간은 미검증이다.
- 본문의 소유자 비교는 DB 권한 검사가 아니다. 운영 백엔드는 인증·프로젝트/경험 소유권·Snapshot을 직접 확인해야 한다.
- 근거 ID와 정확한 인용 확인은 의미 판단의 정확성을 보장하지 않는다. 별도 평가 사례가 필요하다.
- 전송 허용 목록은 현재 가상 샘플을 위한 제한이다. 실제 데이터 사용과 대규모 검색은 후속 통합 범위다.

현재 가상 샘플 개발 범위에서 추가로 확인된 차단 수준의 코드 결함은 없다.
실제 모델 연결 성공이나 운영 배포 준비 완료로 해석해서는 안 된다.
