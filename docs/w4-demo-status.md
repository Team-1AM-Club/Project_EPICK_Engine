# 현재 데모 결과가 보여주는 범위

확인일: 2026-09-09 v4. **Gemma 12B 추출 → Gemma 26B 판단 → 코드 정렬을 실제 연결했고 상세 문항 5개를 적용했다.**
새 비교 336회와 별도 조합 시연 52회·보완 판단 35회를 기록했다. 모델 선정은 정답 미승인·필수 검사 실패로 보류했다.
[최신 성적·오류·상세 시연](w4-review-v4-2026-09-09.md)을 참조한다. 이전 단독 모델 시연은 [v3 기록](w4-review-v3-2026-09-09.md)에 보존했다.

현재 공유용 예시는 두 모델 조합의 [실제 추출](../output/staged-demo-v4-20260909/live-extraction.json),
[협업 추천](../output/staged-demo-v4-20260909/live-collaboration.json),
[학습 추천](../output/staged-demo-v4-20260909/live-learning.json)이다.
상세 문항은 [전문성](../output/staged-demo-v4-20260909-r2/detailed-expertise.json) 등 `staged-demo-v4-20260909-r2/`의 다섯 결과를 본다.
R2는 첫 실제 추출을 재사용해 새 판단을 호출했다. 이를 새 추출 측정으로 중복 계산하지 않는다.
팀 성과만 기록된 경험의 `NEEDS_CONFIRMATION`까지 실제 반환했다. `inference.mode=LLM`, `CAPTURED`는 실제 응답이며,
`PREVIEW_ONLY`는 이번 정답·가중치가 미검토 초안이라는 뜻이다. 모델을 가짜로 호출했다는 뜻이 아니다.

이 결과는 **“가상 원문을 실제 로컬 LLM으로 분석해 추천까지 연결한 개발 시연”**으로 설명할 수 있다.
실행 완료와 내용의 정확도는 별개이며 “최종 선정 모델의 검증된 추천”으로 설명할 수는 없다.
이전 Qwen3-4B·Granite Micro의 실패는 [v1 실행 기록](w4-local-evaluation-2026-09-08.md)에 보존했다.
이전 4개 모델의 v2 성적과 당시 시연은 [v2 실행 기록](w4-local-evaluation-v2-2026-09-08.md)에 보존했다.

아래 표는 이전에 만든 규칙·모의 파일에 대한 설명이다. 최신 실제 실행과 구분한다.

| 파일 | 실제로 실행한 것 | 팀에서 검토할 수 있는 것 |
|---|---|---|
| `collaboration.json` | 가상 문항·경험에 직접 작성한 규칙을 적용 | 추천 응답 형식, 근거 연결, 정렬 규칙 |
| `learning.json` | 가상 문항·경험에 직접 작성한 규칙을 적용 | 문항에 따른 후보·이유·한계의 표현 |
| `diagnostic.json` | 기업정보 사용 제한과 규칙 기반 추천 처리 | 사용할 수 없는 기업정보의 제외·진단 처리 |
| `evidence-extraction-demo.json` | 가상 원문과 미리 작성한 분류 응답을 추출 코드에 입력 | 원문 위치 연결, 주체·계획 분류를 받은 뒤의 처리, 누락 항목 반환 |
| `evaluation-demo/report.json`, `cli-report.json` | 미리 작성한 모의 모델 응답을 채점 | 채점 계산·오류 기록·추천 보류 처리 |

추출 결과는 `inference.mode=SIMULATED_LLM`, 비교 보고서는 `status=PREVIEW_ONLY`이고 모델 추천은 `WITHHELD`다.
협업·학습·진단 결과의 `pipeline_version=w4-local-rules/0.1`은 규칙 실행을 뜻한다.
해당 결과의 `COMPLETED`는 요청 처리가 끝났다는 상태이며 실제 AI 기능의 구현·품질 검증 완료를 뜻하지 않는다.
코드 테스트 통과 개수도 LLM의 추천·추출 정확도 점수가 아니다.

위의 이전 파일을 공유할 때의 설명은 **“입출력 계약과 처리 규칙을 검토하기 위한 개발용 결과”**다.
“LLM이 원문을 읽고 자동으로 추천한 실행 결과” 또는 “평가에서 우승한 모델의 추천 결과”로 설명할 수 없다.

최신 시연은 로컬 모델의 실제 응답을 원문 근거와 연결하고 4단계 판단·5단계 추천까지 실행했다.
실행 모델·설정·입력·출력·원시 HTTP 기록을 함께 보관했다. SK하이닉스 문항별 상세 기준 초안의 자동 적용과
사람이 검토한 정답을 통한 품질 확정은 아직 완료하지 않았다.

공급자 연결, 문항 해석·경험 매칭 평가, 원문 추출 정확도 평가는 [작업 순서](w4-workflow.md)의 별도 작업으로 유지한다.
